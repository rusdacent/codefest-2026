# Мастер-класс на CodeFest'16

Open source на страже Kubernetes Runtime Security \
https://16.codefest.ru/lecture/3259

## Тезисы
Мастер-класс ориентирован на широкий круг слушателей. Он включает в себя несколько секций, в содержании которых мы планируем:

- рассказать, что и как можно сделать для подготовки образов контейнеров и описаний деплоя (манифесты/Helm-чарты) до выкатки на тестовый стенд, препрод или прод
- наглядно представить проблематику, существующую в рантайме, когда наши сервисы работают в Kubernetes
- поделиться информацией о существующих и популярных open source инструментах, позволяющих отслеживать события и состояние кластера; продемонстрировать на стенде их возможности
- обсудить проблемы участников и познакомиться с процессом мониторинга и организацией безопасности их кластеров
